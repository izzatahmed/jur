# تحديث استقرار الجوال — UJ Open Research Hub 3.1

**الغرض:** معالجة مسارات تعطل تحميل الصفحة عند تبديل اللغة أو الثيم وإعادة فتح الموقع عبر متصفح الهاتف. التحسينات تحمي تهيئة الصفحة إذا رفض المتصفح قراءة/كتابة `localStorage`، وتفرض تحديث ملفي CSS وJavaScript، وتحاول إعادة تحميل التنسيق مرة واحدة إذا لم يظهر.

## ماذا ترفع إلى GitHub؟

ارفع **فقط** الملفات الخمسة داخل `docs/` إلى نفس مساراتها في المستودع العام **`jur`** (الفرع `main`):

1. `docs/index.html`
2. `docs/assets/app.js`
3. `docs/publications/index.html`
4. `docs/publications/article.html`
5. `docs/publications/assets/publisher.js`

اختر استبدال الملفات القديمة عند رفع الملفات من خلال واجهة GitHub أو ادخل إلى المجلد وقم بتعديل الملفات. **لا ترفع مجلد `docs` داخل `docs` أخرى.** لا تمس `docs/config.js` أو `worker/` أو مستودع `jus` الخاص أو `docs/editorial-demo/`، ولا تغيّر مفاتيح Cloudflare أو اتصال رفع المخطوطات.

## اختبار بعد التحديث

1. افتح `https://izzatahmed.github.io/jur/` على الهاتف في نافذة عادية، وليس في نافذة خاصة.
2. بدّل بين العربية والإنجليزية، ثم الثيم الفاتح والداكن، وكرّر العملية خمس مرات.
3. أغلق الصفحة وافتحها من جديد، ثم افتح `/jur/publications/` ومقالة تجريبية، وكرّر تبديل اللغة والثيم.
4. تأكد من ظهور زر التقديم ووضع PILOT وعدم تغيّر مسار الرفع. لا تختبر رفع ملفات حقيقية حساسة؛ يمكن استعمال ملف افتراضي فقط.
5. إذا ظهرت مشكلة بعد هذا الإصلاح، التقط صورة للشاشة واسم المتصفح ورقم إصداره. وأرسل نص رسائل Console إن أمكن، من دون أسرار أو بيانات مرضى.

## الصلاحيات وحدود الإصلاح

هذا إصلاح وقائي مبني على فحص ملفات المصدر المطابقة لحجوم الملفات التي عرضها فاحص الموقع، لكنه **ليس إثباتاً قاطعاً** لسبب الشاشة البيضاء على جهاز معين. لا يوجد تعديل في الخادم أو البيانات الخاصة أو الثوابت الخاصة بنظام الرفع.
