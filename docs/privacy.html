Privacy & Prototype Terms

Important: This portal is an independent prototype prepared for consideration by the University of Jordan. It is not a university-operated manuscript submission platform, certified scholarly publisher, or approved medical-data repository.

Demonstration mode

By default the form runs in demonstration mode. Entered details and selected files remain inside your browser. Clicking Submit produces an illustrative receipt; no material is transmitted to the developer or deposited in GitHub.

Configured live pilot mode

Only if the site administrator explicitly configures a secure backend and Turnstile, submission data and a manuscript will be sent over HTTPS to a Cloudflare Worker, which writes the file and metadata to a private GitHub repository controlled by the site administrator. GitHub and Cloudflare may process submitted information under their respective services and terms. No automatic public release takes place. No email notification, deletion service, retention policy, scientific review, or full malware scanning is included in this prototype.

What can be collected in live mode

Corresponding author name, email, affiliation, country, optional ORCID; title, abstract, keywords, study type, field, ethics declaration, consent confirmations, and a PDF or DOCX manuscript. Files are limited to the configured size. The website does not ask for passwords or banking information.

Prohibited submissions

Do not submit personally identifiable health information, patient names, medical record numbers, identifiable case images, classified or confidential third-party research, protected unpublished data, or information you lack authority to disclose. Clinical or sensitive material requires appropriate institutional data governance, malware scanning, access controls, a retention policy, and a production-grade publishing infrastructure before real use.

Security and publication status

Researchers should not treat a submission receipt as publication, peer review, certification, copyright transfer, or scientific approval. Any public research library entries displayed on the website are synthetic examples and do not represent actual submissions. The prototype does not guarantee confidentiality or continued storage and must not be used as a production clinical manuscript portal without security and legal review.

Administrator responsibilities

The administrator must keep the GitHub destination repository private, store GitHub and Turnstile secrets only on the server, activate abuse controls, define privacy and retention policies, arrange malware scanning, and obtain university authorization before representing this service as official.

Prototype terms dated November 2026. Adjust these terms and obtain appropriate legal review before accepting real research submissions.
