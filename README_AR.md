# تحسين اتساق ألوان الثيم — الإصدار v3.1.5

هذا تحديث **بصري فقط**، يستهدف النوافذ والبطاقات التي بقيت فاتحة في الوضع الليلي أو بألوان غير متناسقة في الوضع النهاري.

## لماذا هذا التحديث محدود؟
أثبت اختبار المستخدم أن v3.1.4 أصلح مشكلة الصفحة البيضاء عند تغيير اللغة. لهذا لا نغيّر `app-v314-20261124.js` إطلاقًا، ولا اتجاه RTL ولا تحميل المخطوطات.

## الملفات المطلوبة
ارفع محتويات مجلد `docs` في الحزمة إلى مجلد `docs` الموجود حاليًا في المستودع `jur` مع **المحافظة على المسارات**:

1. `docs/index.html` — استبدال (نفس ملف v3.1.4 مع إضافة رابط CSS واحد).
2. `docs/assets/theme-coherence-v315-20261124.css` — ملف جديد.
3. `docs/publications/index.html` — استبدال (إضافة رابط CSS واحد).
4. `docs/publications/article.html` — استبدال (إضافة رابط CSS واحد).
5. `docs/publications/assets/publisher-theme-v315-20261124.css` — ملف جديد.

## لا تعدّل
`docs/config.js`، ملف JavaScript الحالي، `worker/`، المستودع الخاص `jus`، `editorial-demo/`، أو ملفات المنشورات PDF والبيانات.

## اختبار موجز
- افتح `https://izzatahmed.github.io/jur/` وحوّل بين الوضعين الليلي والنهاري.
- تحقق من بطاقة مسار المخطوطة، نموذج إرسال المخطوطات، رسائل النجاح والخطأ، لوحة التقييم، ونافذة تفاصيل البحث.
- جرّب العربية والإنجليزية عدة مرات، وأعد فتح الصفحة. يجب ألا ترجع الصفحة البيضاء.
- افتح `https://izzatahmed.github.io/jur/publications/` وصفحة مقال، واختبر الثيم فيهما.

## التراجع
استعد فقط ملفات HTML الثلاثة السابقة. لا يلزم حذف ملفات CSS الجديدة.

## حدود التحقق
أجريت مراجعة ساكنة وصياغة CSS والتحقق من الروابط محليًا. ستبقى التجربة على جهاز الهاتف الذي ظهرت فيه المشكلة هي الاختبار النهائي.
