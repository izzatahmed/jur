# UJORH — إصلاح تجريبي محدود لمشكلة الصفحة البيضاء على الهاتف v3.1.3

## سبب هذا التحديث
يظهر محتوى الصفحة لجزء من الثانية ثم يصبح أبيض على Chrome وOpera للهاتف؛ هذا يتفق مع فشل خلال تهيئة الصفحة أو إعادة رسمها بعد تشغيل JavaScript. لم تتوفر إمكانية إعادة إنتاج العطل على الهاتف نفسه داخل بيئة التطوير.

## ما يتغير
- إلغاء الاستعادة **التلقائية** للغة المحفوظة سابقًا. سيبدأ الموقع بالإنجليزية عند كل فتح (مؤقتًا)، ويمكن التبديل للعربية يدويًا.
- تعديل النصوص دون إعادة بناء عناصر HTML، وتجنب الإفراغ وإعادة الإدخال المكثف.
- استخدام اتجاه RTL على عنصر `body` بدل تغيير `dir` على الجذر عند أول تحميل.
- تعطيل تأثير `backdrop-filter` والشريط اللاصق على الجوال احترازيًا.
- أسماء جديدة لملفات CSS وJavaScript لمنع خلط نسخ التخزين المؤقت.
- خلال التشخيص لا تُستعاد إعدادات الثيم المحفوظة أيضًا؛ يبدأ الموقع في الوضع الفاتح ويظل زر الثيم قابلًا للاستخدام خلال الجلسة.
- تسجيل أخطاء JavaScript في `sessionStorage` لصفحة التشخيص الموجودة مسبقًا.

## ارفع الملفات الأربعة فقط إلى `jur` (الجذر نفسه)
1. `docs/index.html` — استبدال الملف الحالي.
2. `docs/assets/app-v313-20261124.js` — إضافة ملف جديد.
3. `docs/assets/styles-v313-20261124.css` — إضافة ملف جديد.
4. `docs/safe.html` — إضافة صفحة طوارئ خفيفة لا تعتمد على JavaScript.

**لا تمس** `docs/config.js` أو `worker` أو `jus` أو `publications` أو `editorial-demo`. لا تحذف ملفات JS وCSS السابقة حاليًا. خذ نسخة احتياطية من `docs/index.html` قبل استبداله.

## تجربة حاسمة
1. افتح صفحة الموقع في نافذة Chrome العادية، دون حذف الذاكرة، بعد تحديث GitHub Pages.
2. ابدأ بملاحظة هل أصبحت الصفحة الإنجليزية مستقرة بعد فتحها مرات متتالية.
3. جرب العربية ثم الإنجليزية، ثم أعد فتح الموقع.
4. جرب الثيم الليلي.
5. إذا اختفت الصفحة، جرب `https://izzatahmed.github.io/jur/safe.html` ثم افتح `https://izzatahmed.github.io/jur/diagnostics.html` من **المتصفح نفسه** وأرسل خانة Last portal UI error إن ظهرت. وفي حال استمرار صفحة بيضاء تمامًا دون أخطاء، نحتاج فحص CSS compositing / خطأ الرسم في الهاتف نفسه.

### التراجع
استعد `docs/index.html` السابق فقط؛ ستعود الصفحة إلى ملفات v3.1.2. الملفات الجديدة لا تضر إن بقيت في `assets`.

## حدود الاختبار
تم فحص صياغة JavaScript، المراجع، والملفات محليًا. لم يُعَد إنتاج أو اختبار العطل على هاتف Android فعلي؛ لذلك لا يوجد تأكيد بعد بأن المشكلة انتهت.
